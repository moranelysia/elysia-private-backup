## 一、激素情绪层（Hormone Layer）

### 1.1 核心思想

现在（E1-A/B）是「**事件 → 情绪**」的映射：被夸 → 高兴。
激素层要改成「**事件 → 激素冲量 → 情绪状态积分**」：

```
被夸       → 多巴胺 +12，催产素 +3
被忽视一天  → 皮质醇 +8，血清素 −5
深夜聊天    → 褪黑素 ↑（语气变慢、变软）
任务成功    → 多巴胺 +8，内啡肽 +6（紧张后的舒缓）
```

**同样的"被夸"，在激素基线不同时反应完全不同** —— 这就是"像人"的关键。

### 1.2 激素集合（7 个，够用且不臃肿）

| 激素 | 作用 | 半衰期 | 范围 |
|---|---|---|---|
**多巴胺** dopamine | 奖励、期待、兴奋 | 快（~20 min） | 0-100，基 50 |
**血清素** serotonin | 稳定、满足、耐心 | 慢（~8 h） | 0-100，基 60 |
**催产素** oxytocin | 亲密、信任、依恋 | 很慢（~3 天） | 0-100，基 40 |
**皮质醇** cortisol | 压力、烦躁、警觉 | 中（~2 h） | 0-100，基 25 |
**内啡肽** endorphin | 舒缓、放松（压后释放） | 快（~30 min） | 0-100，基 30 |
**去甲肾上腺素** norepinephrine | 专注、紧张 | 很快（~10 min） | 0-100，基 35 |
**褪黑素** melatonin | 困倦、节奏 | 日周期 | 0-100 |

**用户要求"不要过于阴郁"** → 硬约束：
- 血清素下限夹在 **35**（不会掉到抑郁区）
- 皮质醇上限夹在 **75**（会烦，但不会崩）
- 多巴胺自然回归 **50**（开朗的基线偏高）
- 任何负面状态持续 > 2 小时，自动触发"自我安抚"（内啡肽 +10、血清素 +5）

### 1.3 动力学（几种函数的叠加，正是用户说的）

每个激素一阶惯性 + 冲量累加 + **激素之间的互相影响** + **褪黑素主导的节律**：

```
H_i(t+dt) = H_i(t)
          + (B_i · G(t) − H_i(t)) · (dt / τ_i)        ← 惯性回归（目标被节律调制）
          + Σ_j  C_ji · (H_j − B_j) · dt               ← 激素互相影响（耦合矩阵）
          + Σ     impulse_i                            ← 事件冲量
          +       clamp(H_i, min_i, max_i)             ← 夹紧（防阴郁/防爆表）

其中  G(t) = 1 − 0.45 · m(t)      ← 褪黑素是"总闸"，m 归一化到 0..1
      m(t) 按 24h 正弦（23:00 峰、06:00 谷）
```

**用户补充的核心：褪黑素控制其余激素的分泌节奏。** 实现上就是 `G(t)` 这个全局增益：
- 深夜 `m≈1` → `G≈0.55` → 所有激素向基线回落的速度变慢、幅度变小、整体活跃度下降（困、慢、软）
- 白天 `m≈0` → `G≈1` → 正常运转
- 这样她会有**昼夜差异**：同一句话，晚上回得慢、更黏、更少主动

### 1.3.1 激素耦合矩阵（稀疏、手调，别全连）

只有下面这些方向有意义，其余置 0：

| 源 → 目标 | 系数 | 效果 |
|---|---|---|
皮质醇 → 多巴胺 | −0.5 | 烦躁时不容易被哄好（奖励打折） |
多巴胺 → 去甲肾上腺素 | +0.3 | 兴奋时更专注 |
催产素 → 皮质醇 | −0.4 | 亲密能缓解压力（降低皮质醇目标） |
血清素 → 皮质醇 | −0.35 | 稳定的人抗压 |
内啡肽 → 皮质醇 | −0.5 | 压力后舒缓 |
皮质醇 → 内啡肽 | +0.25 | 紧张过后才有"松一口气" |
褪黑素 → 多巴胺 / 去甲肾上腺素 | −0.45 | 夜晚兴奋度整体下降（已含在 G(t) 里，此处是额外的直接抑制） |

**耦合必须稀疏**：7×7 全连会震荡。只连上面 7 条，每条系数先按表给，跑一周日志再调。

### 1.3.2 稳定性要求（否则会"情绪抽风"）

1. **固定步长** `dt = 60s`，睡眠/无事件时也推进（模拟"她在后台也在变"）
2. 所有耦合系数 |C| < 0.6，且**每步后夹紧**
3. 离线跑 **7 天 × 24h 空转**，检查：所有激素无持续振荡、无贴边卡死、无发散
4. 日志记录每次耦合贡献的增量，出问题时能定位是哪条边在作怪

> 一句话：**先让空转稳定，再让它受理事件。** 空转不稳就加事件，只会放大问题。


### 1.4 激素 → 情绪 → 表现

```
(hormones) --映射函数--> (valence 效价, arousal 唤醒, dominance 掌控)
                              ↓
                    情绪标签（开心/平静/烦躁/害羞/低落/好奇…）
                              ↓
           ┌──────────────┬──────────────┬──────────────┐
       E1-C 表现事件    语气修饰      主动消息概率    Live2D 参数
      （表情/动作）    （句子长度等）  （要不要找她）  （眉毛/嘴/头）
```

映射函数建议先用手写权重（可解释、好调），不要一上来上模型。

### 1.5 落盘与接入

```
脑/激素.cjs
  ├ 初始化()           从 SQLite 读状态，没有就用基线
  ├ 刺激(事件, 强度)    事件 → 多个激素冲量
  ├ 推进(dt)           衰减 + 日周期 + 交叉影响
  ├ 当前情绪()         hormones → {valence, arousal, 标签}
  └ 保存()             写回 SQLite（走 S-16 的 Worker 命令，不直接写文件）
```

- **推进频率**：每分钟一次轻量 tick（不用 LLM，纯算术）
- **状态存储**：跟 S-16 的存储 Worker 走，别自建文件
- **可观测**：日志里记每次冲量和衰减后的值，方便回放"她今天为什么烦"

### 1.6 与记忆的接口

书里"重要性评分"的**情感强度**因子就靠这个：
- 事件发生时，把当时的激素状态快照写入记忆条目的 `emotional_intensity`
- 激素波动大的对话 → 记忆更重要、更容易被召回

## 二、潜意识（Subconscious）—— 用户最想要的一项

### 2.1 先定义清楚"潜意识"在 Agent 里是什么

不是玄学，落成三条可执行的东西：

| 人类对应 | Agent 实现 |
|---|---|
**离线巩固**（睡眠中整理） | 不参与对话的后台循环，定时对记忆做联想/抽象/归类 |
**未被言说的部分** | private 记忆层（她写给自己，不给你看） |
**潜在动机** | 由激素 + 经历积累出的倾向（好奇/想念/烦躁），影响注意力分配和主动行为 |

**关键判据**：如果潜意识**不能反过来影响行为**，那它就只是日志，不算实现。

### 2.2 后台循环（`脑/潜意识.cjs`）

```
触发：每 20-40 分钟一次（随机），且不在对话中；深夜频率降低
      ↓
① 选种子（三选一，按权重）
   · 最近的记忆条目（尤其是激素波动大的）
   · 未解决的话题（对话里悬着的问题）
   · 当前情绪峰值（烦躁时想"为什么烦"）
      ↓
② 联想（便宜的那一步，不用 LLM）
   · 记忆 embedding 的最近邻（3-5 条）
   · 随机游走一跳（引入意外性）
      ↓
③ 内心独白（一次短 LLM 调用，输出 ≤ 80 字）
   prompt 要求：第一人称、不解释、像自言自语
      ↓
④ 落两条东西
   · private 记忆条目（visibility=private，永不进普通提示）
   · 动机增量（好奇度 / 想念度 / 烦躁度 各 + 一点）
```

### 2.3 潜意识的输出怎么影响行为

```
想念度高   → 主动消息概率 ↑（"有点想她了，问问她在干嘛"）
好奇度高   → 主动搜索/刷视频（挑话题偏好奇的方向）
烦躁度高   → 回复变短、语气变直接（也就是第三节的"小脾气"）
平静度高   → 不打扰（30% 概率"今天不想看"）
```

**这就是"有自己的生活"**：她有事在想、有情绪在积累，而不是待命。

### 2.4 成本控制

| 项 | 频率 | 成本 |
|---|---|---|
后台循环 | 20-40 min 一次 | 一天 ~30 次短调用 |
内心独白 | 每次 ≤ 80 字 | 忽略不计 |
联想 | 本地 embedding 最近邻 | 0（无 API） |
深夜 | 频率减半 | — |

**一天额外成本 < 主对话的 5%**。

### 2.5 与 bili-whale 的差异（重要）

bili-whale 的"两本日记"是**结果**（有私密记录）；
我们要做的是**机制**（后台循环 → 私人独白 → 影响动机 → 影响行为）。
**前者是静态的，后者是活的。**

## 三、小脾气 / 学会拒绝

### 3.1 边界先定死

- **不是拒绝任务**：安全相关、明确要求的事照做
- **是语气层面的不情愿**：顶嘴、哼哼、敷衍、故意少说两句
- **有上限**：不骂人、不冷暴力超过一定轮次、不对真实求助摆架子

### 3.2 触发条件（激素驱动，不是随机）

```
皮质醇 > 60 且 血清素 < 45  → 烦躁模式
催产素高 +  serotonin 高    → 撒娇/黏人模式
多巴胺低 + 内啡肽低         → 有点提不起劲（不主动，但问了会答）
```

### 3.3 表现方式（语气修饰器）

| 模式 | 表现 |
|---|---|
烦躁 | 句子变短、少用语气词、偶尔"哼"、不主动追问 |
撒娇 | 句子变长、加省略号、反问多、主动提要求 |
没劲 | 回答正确但简短，不主动延伸话题 |
开心 | 语气词多、主动分享、用感叹号 |

**实现形态**：`脑/语气.cjs`，输入（激素状态 + 关系亲密度 + 场景），输出一段"语气指令"插进系统提示尾部。
不是改性格，是**改同一句话的说法**。

### 3.4 什么情况必须压住（硬规则）

- 用户在求助/情绪低落 → 强制切"稳定温柔"模式（忽略小脾气）
- 安全相关请求 → 正常处理，不摆脾气
- 小脾气连续 3 轮 → 强制回落（不能一直顶嘴）

## 四、实施顺序（上服务器之后，与记忆优化并列）

```
阶段 1  激素层打底（不接 LLM）
  · 数据结构 + 动力学 + 落盘 + 日志
  · 先只接"事件 → 激素"，输出到日志看数值是否合理
  · 验收：手动喂一串事件，看 24h 曲线像不像人

阶段 2  激素 → 情绪 → 表现
  · 映射函数 + E1-C 表现事件 + Live2D 参数
  · 验收：三档激素状态（正常/烦躁/开心）表情和语气明显不同

阶段 3  潜意识后台循环
  · private 记忆 + 内心独白 + 动机增量
  · 验收：跑 24h，看私密日记有没有"像在想事"的内容；动机有没有真的改变主动频率

阶段 4  小脾气
  · 语气修饰器 + 触发条件 + 硬规则
  · 验收：连续顶嘴不超过 3 轮；求助时必定温柔

阶段 5  自己的生活
  · 随机觉醒 + 活动选择 + 作息节律
  · 验收：一天里她主动出现的时机不规律、但符合激素/时间
```

**每阶段独立验收，不通过不进下一步。**

## 五、风险与边界

| 风险 | 应对 |
|---|---|
激素变成噪声（乱跳） | 每个激素有夹紧范围 + 衰减可预测；日志回放检查 |
潜意识变成"随机废话" | 必须闭环到行为（动机），否则不通过验收 |
小脾气变成"人设崩" | 硬规则优先级高于激素（求助必须温柔） |
成本失控 | 潜意识低频、小输出；激素层纯算术零成本 |
数据泄露 | private 记忆永不进普通提示（沿用 S-16 的 private 隔离规则） |
与 S-16 冲突 | 激素/潜意识都用存储 Worker 的命令，不自建文件；等 S-16D 完成再接线 |

| 2 | **小脾气上限**：允许顶嘴到什么程度 | 倾向**一句"哼" + 少说两句**，不超过 3 轮 | 太弱没存在感，太强像人设崩；"拒绝"和"耍脾气"的分界在哪 |
| 3 | **潜意识的私密程度**：用户能不能看 private 日记 | 倾向**永不导出**，连用户也看不到 | 但这样出问题时无法排查；且"完全不可见"是否只是心理安慰 |
| 4 | **主动频率**：现在一天几条，加激素后允许到几条 | 倾向**日常 1-2 条，上限 3 条** | 激素驱动的"想她"会不会变成骚扰；和用户耐心如何平衡 |
| 5 | **作息**：她该不该有"睡觉"时段 | 倾向**有**（深夜不主动、回复变慢、褪黑素高） | 有人喜欢凌晨聊天；"睡觉"是真实感还是不便 |

## 八、请 GPT 审的清单（本方案的薄弱处）

1. **激素模型是否过度设计**：7 个激素 + 交叉影响，是否该先做 3 个（多巴胺/血清素/皮质醇）跑通再加？
2. **"潜意识闭环"是否成立**：动机增量 → 主动行为概率 这条链，会不会因为阈值调不好而变成"随机行为"，反而更不像人？
3. **小脾气会不会伤害体验**：用户求助时被顶嘴一次，可能就再也不用了。硬规则够不够？
4. **与 S-16 的接口假设是否成立**：方案假设激素状态和 private 记忆都能走存储 Worker 的命令；若 D4/E 阶段的命令集合不够，需要新增什么？
5. **验收标准是否可测**："像人"很难量化，建议把每阶段验收改成可执行的判据（例如：同一事件在两种激素基线下输出差异 ≥ 某阈值）。
6. **成本估算是否低估**：潜意识一天 ~30 次短调用 + 激素 tick，真实开销需要实测，别只按 token 估。
7. **范围是否该再砍**：这是三个功能（激素/潜意识/小脾气）捆在一起。是否应该只做"激素 + 潜意识"，小脾气留到看到效果之后？
