# S-12A 独立Node健康启动

日期：2026-10-25。实现为`core/运行配置.cjs`和`tools/启动无界面核心.cjs`。本步只实现健康启动，不加载聊天、记忆、凭据、Electron或后台业务；不修改现有桌面入口。

## 使用与输出

命令由可信本机终端执行，配置必须是绝对路径、文件名必须为`headless.config.json`：

```text
node tools/启动无界面核心.cjs --config <隔离根的绝对路径>/headless.config.json --once
```

省略`--once`时为本地JSON行协议：每行只能是`{"操作":"health"}`或`{"操作":"shutdown"}`。启动先输出一次健康；收到shutdown输出stopped并停止读入；EOF也退出，最后一行没有换行仍处理。没有网络监听端口，不能接收聊天或执行工具。

健康输出严格为：

```json
{"版本":1,"模式":"health","状态":"healthy","业务就绪":false,"模型已加载":false,"渠道已连接":false,"后台任务":0}
```

非法参数/配置退出码2，输出固定错误代码，不输出原路径、配置正文、秘密或堆栈。非法JSON/命令返回固定错误，可继续健康查询；单行输入超过1024 UTF8字节则拒绝并退出2。分片中文通过StringDecoder处理。SIGINT/SIGTERM注册清理处理；本轮实际验证的是本地关闭/EOF，真实POSIX信号行为留Linux环境验证。输出通道错误退出1。

## 配置与隔离布局

配置只接受以下字段，没有默认配置回退，支持UTF8和UTF8 BOM：

| 字段 | 要求 |
|---|---|
| 版本、模式 | 固定1和health |
| 隔离根 | 已存在的专用测试根，不得为链接；不能是源码/识别到的正式工作区/旧副本或它们的祖先目录 |
| 工作区 | 隔离根内绝对目录路径 |
| 角色卡 | 隔离根内文件路径，与配置/标记/业务写入根分开；健康模式不读取文件正文，允许尚不存在 |
| 数据目录、缓存目录、学习区 | 隔离根内互不重叠的三个目录路径，不能等于隔离根 |
| 附件目录 | 数据目录内目录路径 |
| 纸条目录 | 缓存目录内目录路径 |
| 进度文件 | 学习区内文件路径 |

根目录还须存在`.elysia-isolated-root.json`，内容仅为`{"版本":1,"用途":"headless-test"}`。标记是受信操作者对专用目录的显式声明，不是认证凭据。只应在新建的测试目录生成，不能给真实数据目录补标记来规避检查。

程序本身不创建根、标记、清单或业务目录。配置及标记必须事先存在，分别限制16KiB/1KiB；健康模式仅读取这两个文件。配置不得夹带Key、URL、模式指令等额外字段。

检查绝对路径、根包含关系、已存在父目录的realpath、根内每一段链接/悬空链接、文件/目录类型、持久根重叠和归属。拒绝UNC/设备路径、Windows ADS、尾随点/空格和保留设备名。源码的普通部署父目录不会仅因是父目录就被全部视为正式工作区，只有存在工作区启动器/配置标识才扩展保护到该工作区。

不设置或修改进程环境。已有ELYSIA_WORKSPACE_ROOT/CONFIG_FILE/PERSONA_PATH/DATA_DIR/CACHE_DIR/学习区/附件目录/纸条目录/进度文件覆盖必须与清单相符；安装版用户数据重定向标志拒绝，不能通过继承环境切回正式目录。模型凭据环境不用于健康模式，也不输出“检测到密钥”等信息。

这是启动时只读验证，不是对目录被其他本机进程随后替换的永久保证。S-12B真正写入前仍须使用受控配置并核对实际目标；不把本步的冻结路径对象当作任意文件访问授权。

## 自动验证与边界

`node tools/测无界面启动.cjs`使用独立系统临时目录，覆盖配置、路径越界/生产保护、链接与悬空链接、环境冲突、BOM、真实Node协议、UTF8分片、EOF、过长输入和独立源码布局。

测试子进程预加载`tools/fixtures/健康启动审计.cjs`，禁止业务/网络模块加载、文件写入和配置/标记之外的数据读取；核对依赖缓存，仅允许健康入口及配置模块。审计仅是测试夹具，不进入日常启动入口，不代替操作系统隔离或不可信Node预加载脚本的防护。

尚未接入C15或真实模型，没有业务就绪与常驻服务声明；单实例/后台生命周期、Linux运行及服务运维仍按后续步骤推进。现有桌面、人格、记忆规则、正式数据与package启动脚本不由本步改变。
