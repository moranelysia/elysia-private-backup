# UI 粉色液态玻璃阶段 5：Live2D 小界面验收

日期：2026-10-23

## 本轮范围

只改 Live2D 加载提示和双击快聊的表面材质、可读性与短交互反馈。未改 Live2D 画布、模型、头发与
身体物理、拖动、右键缩放、语音口型、底部羽化、透明窗口边界、快聊尺寸、消息或输入逻辑。

## 自动验收结果

- 新增 `renderer/live2d-粉色玻璃.css`：只覆盖 `#加载状态`，用静态粉白/淡紫渐变、内高光和细边缘
  提升层次；加载完成后的淡出仍可正常结束并隐藏，不影响鼠标事件。
- 新增 `renderer/粉色玻璃-Live2D快聊.css`：所有规则都限定在 `body.快聊模式`，普通主聊天不会
  命中；快聊顶栏、双方气泡、输入区与输入框改为更清晰的静态玻璃层次。
- 小窗内部计算样式的 `backdrop-filter` 均为 `none`，没有新增 WebGL、SVG 滤镜、新依赖或
  `transition: all`；提供 `prefers-reduced-motion` 降级。
- 隔离 Electron 前后截图中，加载胶囊及快聊的外壳、顶栏、聊天区、双方气泡、输入区、输入框和
  发送按钮矩形逐项一致；输入框仍可获得焦点并编辑。
- `测Live2D绑定.cjs`、`测Live2D缩放.cjs` 通过；真实模型的双击快聊、分层待机、语音口型与底部
  羽化回归通过；主界面布局 15/15、多对话 68/68。

对比图：`.cache/UI阶段5-Live2D-前后对比.png`

## 待用户人工验收：观感与手感

1. 重启正式程序后观察桌宠底部短暂出现的“正在唤醒身体…”，确认粉色边缘与阴影清楚但不抢模型。
2. 等模型出现后双击桌宠，确认快聊仍贴近桌宠出现，尺寸和位置没有跳动。
3. 对比双方消息：她的气泡应为偏粉白，你的气泡应带很淡的紫色；两边文字都容易读，但不应厚重得像
   不透明卡片。
4. 在输入框输入、选择文字并发送，确认焦点环清楚，发送按钮按下反馈短促，消息滚动没有卡顿。
5. 点击右上角收起，再连续双击打开、收起两三次；确认快聊不重排、不闪黑，桌宠的拖动、右键缩放和
   头发/身体待机摆动仍与修改前相同。

## 回退

- 移除 `renderer/live2d.html` 对 `live2d-粉色玻璃.css` 的引用，可单独回退加载提示。
- 移除 `renderer/index.html` 对 `粉色玻璃-Live2D快聊.css` 的引用，可单独回退快聊表面。
- 两个覆盖层都不承载业务逻辑，回退不会影响阶段 1–4、账本跟随或 Live2D 模型行为。
