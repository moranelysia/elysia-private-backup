# 爱莉希雅桌面陪伴 Agent：产品目标

更新日期：2026-10-09

详细排期与低时间投入执行方式见 `制作方案.md`。

## 一、产品定位

这是一个长期驻留在 Windows 桌面的陪伴型 Agent。AI 角色设定以《崩坏3》的爱莉希雅为原型，通过稳定人格、长期记忆、声音和角色表现形成持续陪伴，同时具备真正完成任务和陪伴学习的能力。

产品的核心不是单独的聊天窗口、桌宠或工具箱，而是让同一个角色在桌面、语音和社交软件中保持连续身份、上下文与关系，并根据场景切换工作方式。

## 二、三种模式

### 1. 聊天陪伴

- 保持爱莉希雅的人格、语气和关系连续性。
- 优先接住最近对话，再按需召回长期事实、共同经历和情绪背景。
- 支持文字、语音输入、语音回复和桌面角色表情动作。
- 允许用户查看、修正、删除和导出记忆。

### 2. 工作

- 把自然语言需求整理为范围清楚、可确认的任务卡。
- 经用户确认后调用文件、命令、浏览器或外部工作 Agent。
- 展示执行进度、权限请求、失败原因和最终产物。
- 工作内容与陪伴上下文分层保存，避免大量工程日志污染角色记忆。

### 3. 学习陪伴

- 读取用户选定的教材和资料，制定阶段计划。
- 讲解知识、生成练习、检查答案并记录学习进度。
- 根据掌握情况调整难度，保留鼓励和陪伴感。
- 学习资料、笔记、练习和长期人格记忆分开管理。

## 三、渠道与多模态

- 通过统一渠道适配层接入主流社交软件；桌面端与各渠道共享会话身份，但分别管理登录凭据和权限。
- 听觉链路包括唤醒、录音、语音识别、对话和语音合成；默认不持续上传麦克风内容。
- 视觉链路支持用户主动发送图片、截取指定窗口或授权摄像头画面，并明确显示当前采集状态。
- 桌面操作链路在用户主动开启后，支持对指定窗口执行受控的鼠标与键盘动作；每次执行可见、可停止、可追溯，默认不后台运行。
- 多模态观察只作为当前上下文和情绪辅助，进入长期记忆前需要独立的筛选、来源记录与删除能力。
- 桌面表现层可连接 Live2D 或其他角色外壳，但角色模型、音色和动作资源与 Agent 核心解耦。

## 四、总体架构方向

```text
桌面 / 语音 / 社交软件 / 图片
              │
              ▼
        统一输入与身份路由
              │
              ▼
      模式路由与上下文编排
       ├─ 聊天陪伴
       ├─ 工作任务
       └─ 学习陪伴
              │
      ┌───────┼────────┐
      ▼       ▼        ▼
   记忆层   工具权限层   多模态服务
      │       │        │
      └───────┼────────┘
              ▼
      文字 / 声音 / 角色表现 / 任务结果
```

所有外部模型、社交渠道、语音和视觉服务都通过适配器接入，核心不绑定某一家供应商。安装包只携带允许分发的程序和资源；API Key、账号登录、私人音色和用户数据均在安装后由用户配置。

## 五、阶段目标

1. **可迁移基础版**：全新人格、空记忆、统一配置、权限边界和稳定测试。目前已经完成。
2. **可安装版**：提供 Windows 安装包、首次启动向导、模型配置、数据目录选择、卸载与升级机制。
3. **完整桌面陪伴版**：打通语音输入输出、角色动作、状态展示和异常恢复。
4. **多模态与渠道版**：增加受控视觉输入和社交软件适配器，实现跨入口连续对话。
5. **可扩展 Agent 平台**：模型、工具、记忆、角色外壳和渠道均可替换，并提供插件接口。
