## 接口与边界

经真实Worker句柄校验的异步仓储门面新增`状态`分组：

```js
const b = await f.状态.打开后端('relations', 'main')
const snapshot = await b.读取快照() // {版本, 数据}，首次不存在为{版本:0, 数据:null}
await b.保存快照(newValue, {预期版本:snapshot.版本, 操作编号:stableOperationId})
await b.关闭()
```

后端没有旧同步接口`读取/保存`，不能直接注入原同步领域。领域调用必须明确await；保存不隐含缓存版本，也不生成操作ID或自动重试。打开后端会生成短期随机能力令牌，这与调用者提供的稳定业务操作ID不同。后端关闭立即停止本地新调用，返回同一关闭Promise；未确认关闭不能当作已释放，也不会自动重开。

多份状态使用`状态.保存快照组([{后端, 数据, 预期版本}, ...], {操作编号})`。每组最多16个不同目标，每份都需显式预期版本；全部业务值、版本、投影、盘元数据和整组原成功回执在一个SQL事务提交。后项冲突/非法或回执写入处失败，前项一起回滚。相同内容不增加文档版本，但该成功操作仍保存运行回执。返回`{好:true, 结果:[{类型,编号,版本}, ...]}`。

只允许来源登记中的固定状态目标，以及严格编号的渠道映射/任务目标；不收文件路径、SQL或任意类型。辅助状态包括图谱/布局、普通日记索引、后台缓冲、desktop/headless用量、工作索引及已登记整理/聚类状态；没有私密日记正文/评估目标，也没有给未登记的learning-index开口。原生投影、渠道映射/任务契约和后台缓冲校验继续执行；空任务也检查端点契约。渠道映射与任务按同一编号核对引用，允许同组先写任务后写映射，拒绝缺映射或删除仍被任务引用的映射。这里是受信核心内部能力，**不是用户接收许可或网络认证**；许可先查和实际任务推进仍须D2C适配。

每个Worker最多64个活后端能力。渠道任务强制独占，其他目标可显式独占；独占与已有非独占也互斥，不只在同一个门面检查。能力仅在当前Worker内有效，重启全部失效；Worker在读取旧成功回执前校验能力。业务指纹包含目标、数据和预期版本，不包含跨代必变的租约令牌；恢复后先查回执、明确取得新能力，再用原ID/原业务参数续做，已提交操作返回首次原结果，未提交的可明确提交一次。旧能力或伪造目标不能借缓存回执绕过检查；没有自动重放unknown。

保留C的64KiB输入/256KiB结果、队列/日志限额，没有静默放宽。既有大状态超过结果上限时明确拒读，不截断、补空或回落JSON，其他目标仍可读。**后续D2B遇到大用量或缓冲须设计有界增量/分页，不能直接声称任意大小文档已适配。** 本轮未改变schema、物理格式或原逻辑包版本。
