# P2 临时记忆自主评估验收

## 自动验收（已完成）

```powershell
Set-Location -LiteralPath 'F:\elysia\爱莉希雅'
node tools\测记忆自主评估.cjs
node tools\测临时记忆提取.cjs
node tools\测临时记忆数据层.cjs
node tools\测临时记忆召回.cjs
node tools\测临时记忆界面.cjs
```

通过标准：各脚本全部通过；普通单次内容不自动晋升，重复、明确记忆意图、强烈且稳定的情感内容
达到阈值后进入长期层；可能替代旧内容的候选保持待处理；故障重试只产生一条长期记录。

## 待用户人工验收

1. 从 `F:\elysia\start-all.cmd` 重启正式程序，保持聊天模式和“长期记忆”开启。
2. 三轮内两次明确说同一个稳定偏好，例如“我特别喜欢雨声”“我还是很喜欢雨声”，第三轮正常聊天。
3. 等后台批处理结束，打开“记忆库 → 长期”，搜索“雨声”。
4. 通过标准：只出现一条对应长期记忆，来源旁显示“自动评估 N 分”以及重复提及或强烈情感的依据。
5. 再说一条普通、一次性的近况，凑满三轮后检查；它不应仅凭一次普通提及自动进入长期层。

模型是否提取候选仍有不确定性；若未产生候选，不算自动评分失败，应保留原话用于后续调整提取提示。

## 回退

撤销本轮代码时移除 `脑\临时记忆自主评估.cjs`，还原 `脑\临时记忆提取.cjs`、
`脑\临时记忆.cjs`、`脑\临时记忆晋升.cjs`、`脑\记忆.cjs`、`main.js` 和 `renderer\chat.js`。
已有通过自动评估写入的长期记忆不会被代码回退自动删除；如不需要，应在记忆管理页逐条人工遗忘。
