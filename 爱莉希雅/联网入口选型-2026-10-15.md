## 1. 架构纠正

本阶段的目标是让爱莉希雅具备可靠、通用、可检查的联网搜索能力。天气只是现有搜索返回披萨店、
ChatGPT 页面等无关结果时暴露问题的第一个回归样本，不应反过来把项目带成天气接口开发。

因此本轮只选择一个**通用搜索入口**：它应能搜索天气、新闻、官方文档、软件资料、价格与普通
网页。天气首先通过同一搜索入口查可靠气象来源，并接受相关性、地点、日期和来源验证。只有后续
实测证明通用搜索对某类实时数据长期不够稳定，才另开架构决策评估专用接口。

本次不申请账号、不填写 API Key、不下载依赖、不修改搜索实现。

## 2. 当前问题

- DeepSeek 请求本身没有内置联网搜索；模型只能提出 `[查:...]`，实际联网由 `脑\动手.cjs` 完成。
- 当前工具抓取 Bing 搜索结果 HTML，页面结构、反爬、重定向和结果质量都不可控。
- 旧实现只要解析出结果就可能报告成功，缺少查询相关性、来源、日期与交叉验证。
- 微软 Bing Search APIs 已于 2025-08-11 退役，不能把 HTML 抓取平滑换成官方 Bing API。

新的搜索入口必须返回结构化标题、URL、摘要和可用日期，并接入已经完成的统一工具回执。搜索
服务只负责寻找材料；“排在前面”或“服务生成了摘要”都不能单独证明事实正确。

## 3. 通用搜索候选

### A. Tavily Basic Search（建议先选）

Tavily 是面向 Agent 的通用搜索 API。第一版只使用 Basic Search，关闭生成答案和原始全文，只取
少量标题、URL、摘要、相关度与发布日期，再由 AAAAgent 本地判断来源、日期和交叉证据。

| 项目 | 结论 |
| --- | --- |
| 覆盖 | 普通网页、新闻、官方文档、天气页面、软件资料等通用搜索 |
| 自用成本 | 每月 1,000 免费 credits，不要求银行卡；Basic Search 每次 1 credit |
| 超额成本 | PAYG 当前为每 credit 0.008 美元；第一版不启用自动付费 |
| 限流 | 开发 Key 为 100 请求/分钟，个人使用足够 |
| 本机资源 | 只发 HTTPS 请求；无常驻进程和本地模型；可直接使用 Node 内置 `fetch` |
| 迁移难度 | 中低，预计 6–10 小时完成适配器、设置、验证、回执和回归 |
| 优点 | 无银行卡；结果结构适合 Agent；支持域名、时间、主题等过滤 |
| 主要风险 | 查询会交给云服务；部分查询可能用于改进服务，自有索引不足时可能转给第三方索引 |
| 可靠性边界 | Tavily 条款也要求独立核验输出；其摘要和相关度不能直接作为完成证据 |

隐私硬规则：只发送从当前问题中提取的最小公开检索词，不发送聊天历史、记忆、文件正文、姓名、
账号、路径或密钥。含私人信息且无法安全改写的问题默认不联网，并明确说明原因。

官方资料：[价格](https://www.tavily.com/pricing)、[credits 规则](https://docs.tavily.com/documentation/api-credits)、
[Search API](https://docs.tavily.com/documentation/api-reference/endpoint/search)、
[限流](https://docs.tavily.com/documentation/rate-limits)、[隐私政策](https://www.tavily.com/privacy)、
[平台条款](https://www.tavily.com/terms)。

### B. Brave Search API

Brave 提供自己的网页索引和更底层的结构化搜索结果，AAAAgent 对来源过滤的控制更直接。

| 项目 | 结论 |
| --- | --- |
| 覆盖 | 通用网页、新闻、图片等搜索；第一版只接网页搜索 |
| 自用成本 | 当前 Search 方案为每 1,000 次 5 美元，并每月赠送 5 美元 credits，约覆盖 1,000 次 |
| 开通条件 | 当前方案要求账号和支付信息，即使使用量在赠送额度内也要绑卡 |
| 本机资源 | 只发 HTTPS 请求；无常驻进程和本地模型；无需 SDK |
| 迁移难度 | 中等，预计 7–11 小时，还要处理配额响应头与结果保存边界 |
| 优点 | 独立索引；本地可以完整控制可信域、排序、日期和交叉验证 |
| 主要风险 | 查询日志可保留最长 90 天；普通方案对保存 API 结果有限制，而 AAAAgent 会保存聊天记录 |
| 适用条件 | 愿意绑卡，并在接入前确认个人聊天历史保存必要引用符合当前方案条款 |

旧文章中的免费次数和价格已经过期，本报告只采用当前官方定价页。官方资料：
[API 与当前价格](https://brave.com/search/api/)、
[认证](https://api-dashboard.search.brave.com/documentation/guides/authentication)、
[限流](https://api-dashboard.search.brave.com/documentation/guides/rate-limiting)、
[隐私说明](https://api-dashboard.search.brave.com/documentation/resources/privacy-notice)、
[帮助与结果保存约束](https://api-dashboard.search.brave.com/documentation/resources/help-feedback)。

### C. 保留 Bing HTML 抓取

| 项目 | 结论 |
| --- | --- |
| 成本 | 无账号、无 API 费用 |
| 迁移难度 | 无迁移，只继续补本地拦截规则 |
| 优点 | 不需要新服务，可以立即使用现有代码 |
| 主要风险 | HTML 结构、反爬、重定向随时变化；没有稳定返回格式或服务保证 |
| 已知表现 | 天气查询曾返回披萨店与 ChatGPT 页面，拦截只能防误报，不能恢复正确材料 |
| 定位 | 只适合作为无 Key 时的实验性备用，不适合作为最终联网搜索入口 |

微软官方说明 Bing Search APIs 已在 2025-08-11 退役，Azure 的 Grounding with Bing Search 是
另一套较重的 Agent 服务，不是本项目的轻量替代。来源：
[Bing Search API 退役公告](https://learn.microsoft.com/en-us/lifecycle/announcements/bing-search-api-retirement)。

## 4. 推荐方案

建议选择 **A：Tavily Basic Search**。它不要求银行卡、没有本地模型或常驻服务，每月约 1,000 次
免费搜索，适合当前个人自用和有限开发时间。实现时必须施加以下边界：

1. `include_answer=false`、`include_raw_content=false`，不使用服务商生成答案替代模型核验。
2. 本地先提取和脱敏最小查询；私人材料不能原样发送。
3. 官方事实优先官方域；时效问题核对发布日期和事件发生日期。
4. 对重要或冲突事实寻找第二来源；单一普通网页只标记“部分验证”。
5. 工具回执显示脱敏查询、来源 URL、日期、验证状态、重试与失败原因。
6. 同一调用最多进行一次有意义的改写或来源限定重试，之后明确失败。
7. 本地记录调用次数并设置月上限；第一版不允许自动产生费用。

## 5. 天气在本阶段的位置

天气保留为通用搜索的强制验收项，而不是独立能力：

- 查询“天津今天的天气”时，结果必须同时匹配天津、天气主题和当天日期。
- 优先中国气象局、中央气象台、地方气象部门等可靠来源；找不到就如实失败。
- 搜索结果中的网页摘要只算检索材料，不能伪装成已核实的实时观测。
- 返回披萨、ChatGPT 或日期不符页面时，统一回执必须标记失败，不交给模型自由改写。

如果接入通用搜索后，固定天气样本仍长期无法取得有效来源，再单独比较天气接口；现在不提前接入。

## 6. 选定后的实现与验收

选定 A 后，下一步只实现通用搜索适配器：设置页保存 Key、脱敏查询、结构化结果、超时/取消、
401/429/断网处理和统一回执。完成后停下来单独验收，再继续来源验证与有界恢复。

首批人工联网验收：

- **天气相关性**：天津今天、天津明天、不存在的地名；核对地点、主题、日期和来源。
- **官方资料**：Node.js 当前 LTS，必须优先 nodejs.org，并显示资料日期。
- **新闻时效**：一个当天事件，区分网页发布时间与事件发生时间。
- **普通事实**：返回两个可打开来源；冲突时必须提示，而不是自行确定。
- **失败路径**：断网、超时、无结果、无效 Key、429 均不得显示成功。
- **隐私**：包含姓名、文件正文、账号或路径的提问不得原样发送。
- **成本**：调用计数可见；达到本地上限后停止，不自动付费。
