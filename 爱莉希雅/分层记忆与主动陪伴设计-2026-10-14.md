# 分层记忆、记忆日记、情感状态与主动陪伴设计

状态：架构已按用户 2026-10-14 的定义固定；M1 数据层和 M2 可视化已经完成，尚未接模型提取、
上下文召回、日记或主动陪伴，也没有迁移真实记忆。

## 1. 四类能力的关系

```text
正式聊天 / 学习 / 工作
          │
          ├─ 当前对话上下文（原文，受 token 预算限制）
          │
          ├─ 短期记忆提取器（后台、失败不影响聊天）
          │       │
          │       ├─ 临时记忆库（详细、分类、1–7 天有效）
          │       └─ 满足规则后晋升到长期记忆或领域记忆
          │
          ├─ 日/周/月整理器 ──> 记忆日记库（只供本地查看，不自动进上下文）
          │
          └─ 情感计算 ──> 文字情绪与温度
                         └─ 统一表现事件 ──> 现有桌宠 / 后续 Live2D

用户活动计时 ──> 空闲随机间隔 ──> 主动陪伴文字 ──> 当前正式会话
```

四条链彼此隔离：日记不能反向生成事实，Live2D 失败不能影响文字，主动陪伴失败不能改记忆，
短期整理失败不能阻塞正常回复。

## 2. 分层记忆

### 2.1 层级

| 层级 | 内容 | 保存时间 | 是否自动进入上下文 |
| --- | --- | --- | --- |
| L0 当前上下文 | 当前会话原文、当前工具结果 | 随对话预算裁剪 | 是 |
| L1 临时记忆 | 近期状态、计划、未完话题、候选偏好、近期事件 | 默认 7 天，可按类缩短或延长 | 只按相关性选少量 |
| L2 长期陪伴记忆 | 已确认事实、共同经历、小本子 | 长期，用户可改删 | 只按相关性选少量 |
| L3 领域记忆 | 学习进度、工作索引/工作摘要 | 各领域自行管理 | 仅在对应模式或明确提及时 |
| D 日记库 | 日、周、月的回顾笔记 | 长期，用户可编辑 | 否 |

现有事实、经历和小本子保持原格式，不做破坏性迁移。第一版新增 L1，并让召回器同时读取 L1、
L2 和当前模式对应的 L3；日记库始终排除在提示词拼装路径之外。

### 2.2 临时记忆的分类

临时记忆不是临时对话。临时对话关闭程序即消失；临时记忆跨重启保存。

第一版固定六类，避免让模型任意发明类别：

- `近期状态`：最近疲惫、感冒、考试周等会变化的状态。
- `近期计划`：几天内准备完成的事和时间点。
- `未完话题`：答应稍后继续、尚未得到结果的问题。
- `候选偏好`：只出现过一次、还不能确定为长期偏好的信息。
- `近期事件`：刚发生但尚未判断是否值得成为共同经历的事。
- `关系语境`：近期互动中的称呼、约定和情绪背景，不直接改写人格设定。

建议字段：稳定编号、类别、正文、创建/更新时间、到期时间、来源会话、来源消息时间、提取方式、
确认状态、相关标签、晋升去向。禁止保存模型的思维过程、完整工具输出、密码和未授权文件内容。

### 2.3 主动写入与晋升

正常回复结束后，由独立后台提取器读取这一轮用户输入、最终回复和已有候选，输出结构化候选；
主聊天模型不再必须依赖 `[记住:...]` 才能留下新记忆。提取失败只写日志。

写入规则：

1. 用户明确陈述的近期计划或状态可以直接进入 L1。
2. 模型推断、玩笑、引用文本和第三方信息只能标为“待确认”，不能晋升。
3. 同一信息在不同会话重复出现，或用户在界面手动确认后，才可提议晋升。
4. 明确且稳定的个人事实进入“事实”；共同完成且有来源的事件进入“经历”。
5. 工作内容只进入工作索引/工作摘要；学习内容只进入学习进度，不能晋升为陪伴事实。
6. 到期项默认归档后再延迟清理，给用户留下恢复窗口；冲突项停止晋升并显示待确认。

第一版自动提取、自动分类、自动去重；长期晋升先采用“本地规则通过后显示待确认”，不让模型
静默改写长期事实。稳定使用一段时间后，再单独评估哪些明确事实可以自动晋升。

## 3. 记忆日记库

### 3.1 定位

记忆日记是本地可读档案，不是模型上下文，也不是长期事实的替代品。她会在后台按时间主动整理，
无需等待用户发出“总结今天”的消息。

第一版提供三种周期：

- 每日：当天发生了什么、完成了什么、未完事项、值得记住的片段。
- 每周：本周主题、变化、反复出现的问题、下周可继续的事。
- 每月：长期趋势和重要节点；第一版可在日/周稳定后再开启。

每篇日记只引用已有聊天、确认记忆、学习进度和工作任务回执。没有资料的栏目留空，不编造。
每一段保存来源编号，界面可以展开查看依据。

### 3.2 主动整理时机

- 每日整理：跨过自然日后，在程序下一次空闲时补写前一天；不要求程序整夜运行。
- 每周整理：新一周首次启动或首次空闲时补写上一自然周。
- 每月整理：新月份首次空闲时补写上月。
- 同一周期使用稳定任务编号，重复启动不会生成重复日记。
- 断网、模型失败或程序退出时保留待处理状态，稍后重试；绝不影响聊天启动。
- 没有新资料时记为“无内容”，不调用模型生成空洞文字。

### 3.3 存储与界面

不为第一版引入 SQLite 或新依赖。建议使用独立索引加逐篇 JSON 文件，原子写入：

```text
记忆/日记/
  索引.json
  日/2026/2026-10-14.json
  周/2026/2026-W42.json
  月/2026/2026-10.json
```

每篇包含标题、周期、起止时间、模块数组、来源列表、生成时间、修改时间和生成状态。模块固定为
“回顾 / 学习 / 工作 / 陪伴片段 / 未完事项”，空模块可隐藏。用户可改标题、正文、模块顺序，
可以新增私人模块；模型再次整理时不得覆盖用户修改，只能生成新版本或补充建议。

可视化入口与现有记忆管理页并列，支持日/周/月切换、时间轴、模块折叠、来源展开、编辑、删除和
导出 Markdown。日记页面只读取日记文件，不把打开或编辑操作送给模型。

## 4. 情感状态与 Live2D

### 4.1 两层状态

- 反应层：由当前一句话和当前事件产生，持续几十秒到几分钟。
- 情绪层：由近期交互缓慢变化，跨几轮对话保存，但会自然回落到中性。

状态建议由“主情绪 + 强度 + 温度 + 活跃度”组成。主情绪使用有限枚举，如开心、关心、认真、
疑惑、难过、惊讶、中性；强度、温度和活跃度限制在固定范围。所有变化记录触发来源和时间，
可以手动复位，不允许无限累加。

### 4.2 输出链

1. 当前内容生成短时反应。
2. 反应与缓慢情绪合成这一轮表达状态。
3. 提示词只收到简短的表达指示，控制措辞、句长、亲近程度和关心力度。
4. 同一个表达状态映射为统一表现事件，驱动现有表情路由。
5. Live2D 接入后读取表现事件，平滑计算表情权重、动作和过渡；模型不能直接控制任意参数。

这里的“温度”指情感表达温度，不直接修改 DeepSeek API 的采样 temperature。采样参数仍由独立
评测决定，避免把情绪变化变成回复随机性和人格漂移。

## 5. 主动陪伴文字

第一版只发送文字，不自动播放 TTS。计时从最后一次真实用户活动开始，而不是从模型回复结束开始。

建议默认规则：

- 空闲间隔每次在 45–120 分钟内重新随机，用户可在设置中修改范围。
- 仅程序正在运行、存在当前正式会话、没有回复/工具/录音/TTS/编辑操作时触发。
- 临时对话、工作任务执行中、全屏或勿扰时不触发。
- 默认安静时段 23:30–08:00，每日最多 3 次，两次之间至少 45 分钟。
- 用户有任何键盘、发送、切换会话或窗口交互，就重置本轮空闲计时。
- 主动消息写入当前正式聊天记录，并明确标记来源为“主动陪伴”，便于删除、统计和关闭。
- 生成时只给模型少量相关临时记忆、当前模式、时间和触发原因，不读取日记库。
- 如果没有具体依据，使用短而自然的在场表达；禁止伪造“我看到你正在做某事”。

设置项至少包括：总开关、随机时间范围、安静时段、每日上限。关闭后立即取消已安排的计时，
下次启动保持关闭状态；首次上线默认关闭，由用户主动开启。

1. **M1 数据层（已完成，2026-10-14）**：临时记忆文件、固定分类、原子写入、到期/归档、
   增删改查与分阶段晋升状态；41 项隔离测试通过，没有读写真实记忆。
2. **M2 可视化（已完成，2026-10-14）**：记忆管理页新增长期/临时切换；支持手动新增、分类、
   生命周期、确认状态、到期时间、来源、标签、编辑、删除、恢复和幂等晋升。临时层仍不进入上下文。
3. **M3 主动提取（已完成，2026-10-14）**：仅在正式聊天且长期记忆开启时，于完整回复落档后
   串行后台提取；每项必须带可在本轮用户输入中逐字命中的依据。固定分类、期限、标签、敏感内容、
   路径和内部标记均在本地校验，规范化精确去重，失败与主回复隔离；所有模型候选保持待确认。
4. **M4 临时层相关召回（已完成，2026-10-14）**：已确认、未到期的 L1 按本轮关键词选择，
   最多 5 条/1000 字；圆环打开实际请求快照，18 项隔离测试通过。L2/L3 原有读取规则保留，

5. **J1 日记数据与调度（已完成，2026-10-15）**：首次只补昨天和上一个自然周，后续按最后
   调度日期补齐；任务号幂等，正文必须引用聊天、已确认记忆、学习进度或工作回执的真实编号。
   无材料不调用模型，断网/解析/磁盘失败延时重试且不影响聊天，用户修改过的文件不被重生成覆盖。
6. **J2 日记界面（已完成，2026-10-16）**：J2-A 时间轴、模块、来源、搜索和日/周筛选完成；
   J2-B 可编辑标题与现有模块正文，保留来源链并标记人工修改。删除留下隐藏标记避免后台重建，
   Markdown 导出仅含日记正文与来源摘要，并省略本机绝对路径。
7. **M5 重要性评分（已完成，2026-10-15）**：临时记忆使用低/普通/重要/核心四级本地元数据；
   召回按相关词、重要性和更新时间给出固定评分与选择原因。相关性保持主导，无关核心项仍被过滤，
   不新增模型请求、向量库或数据库；长期层排序留待单独验收。
8. **M6 冲突与替代（已完成，2026-10-15）**：明确更正可在原有后台提取中提出稳定编号关系；
   新候选保持待确认，用户选择替代或并存。替代使用原子写入、内容快照和可追溯关系链，已被替代
   的旧条保留但退出召回。模型只能提议，不能自行覆盖。
9. **M7 混合召回（已完成，2026-10-15）**：关键词为空时先按本地意图分类补充；仍为空且明确
   询问历史记忆时，才让现有 DeepSeek 从有效候选编号中语义补选。无新依赖，失败退回本地结果，

10. **E1 情感状态（已完成，2026-10-16）**：E1-A 即时反应层、E1-B 缓慢情绪层和 E1-C 统一

11. **P1 主动陪伴（主体完成，2026-10-16）**：P1-A 本地调度、P1-B 设置/活动接入和 P1-C
    受限文字生成/正式聊天落档均已完成。默认关闭，强制执行随机间隔、安静时段、每日上限、最短
    间隔和忙碌避让；只读取至多两条已确认短期资料，不读日记、不用工具、不自动朗读。生成期间
    用户回来会中止，只有带“主动陪伴”来源成功落盘才计数。P1-D 已增加最近八条本地相似度去重
    和生成中、已发送、失败、取消、拦截等可见运行状态；阈值后续只按真实误判样本校正。
12. **L1 Live2D 表现控制器（继续后移）**：用户预计短期拿不到新模型；不阻塞主动陪伴及核心
    Agent 主线，等素材可用后复用 E1-C 事件接口推进。

## 7. 验收红线

- 临时记忆、日记和主动消息都能看到来源，模型不能悄悄改掉用户手写内容。
- 日记文件不出现在任何自动提示词或上下文统计中。
- 推断内容不能自动晋升长期事实；冲突内容不能靠新旧顺序静默覆盖。
- 后台整理失败、断网或 API 限流时，聊天和现有记忆保持可用。
- 情感状态必须衰减、可复位，不能让一次情绪永久改变人格。
- 主动陪伴可彻底关闭；安静时段和每日上限由本地程序强制执行，不交给模型自觉遵守。
