# 爱莉希雅 0.2.2 可迁移自用版

构建日期：2026-10-09

## 文件

- `dist/Elysia-Setup-0.2.2-x64.exe`：Windows x64 安装版，推荐日常使用。
- `dist/Elysia-Portable-0.2.2-x64.exe`：免安装便携启动器。

## 首次启动

首次启动会在当前 Windows 用户的数据目录中自动创建：

```text
%APPDATA%\爱莉希雅\
├─ elysia.cosplay.v2.json   全新角色卡
├─ 记忆\                    空记忆和空聊天记录
├─ 学习\                    材料、笔记、练习
└─ 缓存\                    设置和临时文件
```

重装和升级不会覆盖角色卡、聊天或记忆。卸载程序默认保留这些数据。

## 模型凭据

0.2.2 不会把开发电脑上的 API Key 写入安装包。打开聊天窗口，点右上角齿轮即可填写、测试或清除 DeepSeek API Key。

设置界面保存的 Key 使用 Electron `safeStorage` 调用 Windows 加密服务，密文位于当前用户的 `%APPDATA%\爱莉希雅\缓存`。完整 Key 不会写入普通设置文件，也不会回传给网页界面。读取顺序为：

1. 设置界面加密保存的 Key。
2. 开发目录中的 `脑\钥匙.txt`（安装包不包含它）。
3. 环境变量 `DEEPSEEK_API_KEY`。
4. 当前 Windows 用户的 DeepSeek Harness 凭证。

“测试连接”会向 DeepSeek 发一条最多 8 token 的短请求，因此会产生极少量 API 用量。清除设置内保存的 Key 后，如果环境变量或 DSH 凭证仍存在，程序会自动回退到这些来源。

## 数据与备份

设置页下半部分提供：

- “打开数据目录”：查看当前人格、记忆、聊天和学习资料。
- “导出备份”：选择位置后生成一个 ZIP，压缩在后台执行，不会卡住聊天窗口。

备份包含人格卡、记忆、聊天、附件和学习资料；不包含 API Key、缓存、机器相关设置和程序文件。ZIP 本身没有密码，请放在只有本人能访问的位置。当前版本只提供导出，恢复入口将在覆盖规则和回滚测试完成后加入。

## 外部能力
