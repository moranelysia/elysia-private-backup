# 爱莉希雅升级报告

日期：2026-10-08

## 0.2.2 用户数据备份（2026-10-09）

- 设置页新增“打开数据目录”和“导出备份”。
- ZIP 包含人格卡、记忆、聊天、附件和学习资料，排除 API Key、缓存、机器设置和程序文件。
- 压缩在独立工作线程执行，备份较大时不会冻结聊天窗口和托盘。
- 拒绝把 ZIP 写进正在备份的记忆或学习目录，并跳过符号链接和 junction，避免递归打包或越界复制。
- 备份相关测试 13/13、设置页视觉检查、最终 app.asar 工作线程和 0.2.2 便携版首次启动均通过。
- 恢复功能需要覆盖确认、自动回滚和损坏包校验，留到下一小版本。

## 0.2.1 设置与凭据（2026-10-09）

- 聊天窗口右上角新增设置入口，可保存、测试和清除 DeepSeek API Key。
- Key 使用 Windows `safeStorage` 加密保存；渲染进程只能看到遮住后的头尾，完整值不会进入普通设置文件或界面日志。
- 保存和清除后立即生效，不需要重启；清除后可以回退到环境变量或 DSH 凭据。
- 新增 9 项密钥存储测试；Windows 加密真机冒烟、设置弹窗视觉检查和最终便携版首次启动均通过。
- 已生成 0.2.1 Windows x64 安装版与便携版，打包敏感内容扫描 0 命中。
- F 盘对称工作区仍未搭齐，因此本轮没有把旧 532 项基线改写成新的完整回归数字。

## 0.2.0 可迁移自用版（2026-10-09）

- 已生成 Windows x64 安装版和便携版。
- 安装版首次启动会在 `%APPDATA%\爱莉希雅` 创建全新人格、空记忆和学习目录。
- 程序代码与用户数据分离，升级、重装和默认卸载不会覆盖用户资料。
- 打包清单明确排除旧人格目录、运行记忆、聊天记录和 API Key。
- 新增 9 项用户数据初始化测试；本地核心测试总计 532/532 通过。
- 未安装版和最终便携版首次启动冒烟测试通过，打包内容敏感扫描 0 命中。

## 本次目标

把项目整理成可安全迁移的独立副本，并确保新机器首次启动时是全新人格，不继承本机用户资料、聊天、记忆、授权或密钥。

## 已完成

- 增加统一配置层，集中管理角色卡、学习区、运行数据、缓存、桌宠和语音服务路径。
- 增加干净迁移生成器。生成物使用全新角色卡、空记忆和空聊天记录，不复制 API Key、旧设置、附件、缓存及旧人格资料。
- npm 缓存改为项目内相对路径，迁移后不再访问原机器的 D 盘目录。
- 加固文件边界，阻止通过 Windows junction 或符号链接绕过白名单访问禁区。
- 把 Shell 执行改成异步调用，避免长命令冻结 Electron 主进程。
- 从 `main.js` 抽出设置存储和进程检测模块；设置文件改为临时文件写入后原子替换，降低异常退出造成 JSON 损坏的风险。
- 修正测试对原机器目录和既有记忆的依赖，使核心测试能在空白迁移环境运行。

## 验证结果

- 本地核心测试：523/523 通过。
- 干净副本隐私扫描：旧姓名、学校、既有经历和原 D 盘路径均无命中。
- 干净副本不包含 API Key、旧设置、旧角色卡和历史聊天内容。
- `D:\新建文件夹` 全程只读，未在其中创建、修改或删除文件。

## 后续建议

下一阶段可继续拆分 `main.js` 的窗口、托盘和 IPC 服务，以及 `renderer/chat.js` 的对话、附件和任务界面。完成拆分后应补一次 Electron 图形界面、联网模型、语音服务和桌宠联调；这些外部集成本次没有实际启动验证。
