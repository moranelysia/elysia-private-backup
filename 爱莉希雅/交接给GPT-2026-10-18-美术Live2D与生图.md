## 二、已完成：脖子（用户确认"可以了"）

### 做法

`neck#1` 图层用 `source_paint` 的 `clear` + `shape`（ellipse, filled）重画：

```
上椭圆   (570,462)-(658,540)   rgb(240,203,190)   ← 上端浅
中段     (570,501)-(658,555)   rgb(232,190,176)
下椭圆   (570,516)-(658,594)   rgb(222,170,158)   ← 下端深
左轮廓线 x=572, y 496-560, 宽 2.0, rgb(150,96,86) alpha 255
右轮廓线 x=656, y 496-560, 同上
```

- 宽度 88 像素，中心 x≈614
- 上端伸进下巴底下、下端埋进衣领，**露出的只有下巴底下一条窄缝**
- **没有顶部描边**（试过整圈描边，顶部那圈会露成黑弧，已去掉）

### 关键教训

- `shape` 的 ellipse 描边是**整圈闭合**，做不到"只画左右边"→ 用 `shape='line'` 单独画两条竖线
- `shape` **没有羽化参数**，纯色填充，做不出柔和渐变 → 脖子看着偏"平"，但因为它 90% 被遮住，可以接受
- 判断"能不能擦"**不能只看图层覆盖率**：脸层是半透明的，脖子本来就透过脸参与成像。擦之前必须导出合成图看效果

## 三、未解决：肩膀黑线（下一轮的重点）

### 真正的根因（今天查明的）

**不是"两块之间有空隙"，是两块各自带着深色像素：**

1. `handwear-l/r`（手臂层）里有一条**黑色三角带**，贴着金色饰边内侧 —— 袖子内侧的黑色衬底
2. `topwear`（躯干层）的**边缘有一道红褐色抗锯齿描边**（拆图时从原画线稿带过来的）
3. 两块拼在一起，手臂一动，这两条深色边就露在肩膀皮肤上 → 看起来像"机器关节"

### 已排除的可能

| 试过的做法 | 结果 |
|---|---|
| 给 handwear 的黑色区域灌肤色（bucket 容差 45） | 无效，可见区域没变 |
| 沿 handwear 上缘刷皮肤色（radius 3.2 / 5.0） | 无效 |
| 沿 topwear 边缘刷皮肤色（radius 3.5-4.0，左右各 1-3 道） | **右肩有效、左肩无效；但把阴影刷没了 → 已全部回退** |
| 加缝份（把 neck/handwear 外扩 18-26px） | 无效，因为是相对错位不是缺口 |

### 为什么失败

1. **坐标靠猜**：没有先做"单层渲染 + 逐层隐藏"的定位，直接刷，左右不对称
2. **一次刷太多**：5 道并行路径把整片阴影盖掉，破坏了原画质感
3. `source_paint` 只有纯色笔刷，**盖住描边的同时也会盖住渐变阴影**

### 建议做法（给 GPT / 美术）

**优先级 1：PS 手工（最省时间）**
- 打开 `seethrough_blink.psd2live` 导出的 PSD，或在 PS 里直接改
- 用**仿制图章**沿肩膀边界取皮肤，覆盖两条深色边
- 优点：能保留渐变，5 分钟的事

**优先级 2：程序化（如果要自动化）**
- 必须先做定位：`view_render_layer` 单独渲染 `topwear#4` 和 `handwear-l#3`，**逐层对比**确定线属于谁
- 只刷**一笔**，导出，看效果，再决定下一笔
- 不要并行刷多条路径

**优先级 3：结构层面（治本）**
- 手臂和躯干是两套 deformer，形变必然错位
- 正规做法：把 arm 和 torso 拆到同一个 warp 下，或者用 `path`（Deform Path）做柔性过渡
- 工作量大，不建议现在做

## 六、MCP 工具速查（PSD2Live）

```
令牌      HKCU\Software\JavaSoft\Prefs\io\github\psd2live\agent → agent_mcp_bearer_token（去掉 "/"）
脚本      美术\Live2D\拆分工作\制作脚本\46-mcp调用.ps1 -名 <工具> -参数 <JSON>
         47-mcp工具列表.ps1 / 48-导出moc3.ps1 / 49-渲染图层.ps1
```

**坑**：
- `workspace_call` 的参数格式是 `{"operation":"xxx","request":{...}}`（不是 arguments 嵌套）
- `history checkout` 需要 `state` + `node_id` 两个字段
- `source_paint` 是 job-backed，`clear` 之后立刻 `shape` 会失败 —— **不要先清空再画**，直接画新形状覆盖
- 中文路径会让 PowerShell 5.1 乱码，脚本文件必须带 UTF-8 BOM；**新目录尽量用 ASCII 名**
- 每步改动后立刻 `48-导出moc3.ps1` + 预览器探针截图验证
