# S-16D3 模型 C1：隔离真实连接与 Worker 用量验收

## 范围与结果

新增 `core/隔离真实模型用量适配.cjs`，显式将已创建的真实连接的异步记账接口绑定到隔离 Worker 的 headless 用量仓储。只在收到实际 Worker 成功回执后确认记账，不自动重试。started 使用 `real-model-请求编号-start`，两个可能终态共用 `real-model-请求编号-end`，可在错误只返回请求编号和记账阶段时推导并查回执；查询到回执不能证明 HTTP 请求已经发出或未发出。版本竞争或写账故障会封闭本连接，不自动重试。

关闭适配器会先关闭连接、等待已经开始的记账任务排空，再关闭用量句柄；排空可能等待 Worker 命令终止，不能把连接的同步关闭当成磁盘已停止。Worker 恢复后旧领域句柄失效，关闭旧句柄可能报 `SQLITE_STATE_CAPABILITY_INVALID`，需要新建句柄；不得据此自动重发模型请求。取消发生于发出 HTTP 后时，账本可能仅留 started，不能推断费用或远端结果。
