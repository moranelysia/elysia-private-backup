# C 语言 · 第一课
## —— 程序是怎么记住东西的

你已经会两件事了：打印一行字、做个加法。
这一课，我们把中间那块补上：**变量**。

别怕这个词，它一点都不神秘。

---

## 一、先看一段最小的程序

    #include <stdio.h>

    int main() {
        printf("hello\n");
        return 0;
    }

逐行看：

`#include <stdio.h>` —— 把"能打印字"的那套工具请进来。没有它，printf 就不认识。

`int main()` —— 程序从这儿开始跑。main 是入口的名字，前面的 int 是"我最后会还给你一个整数"。

`return 0;` —— 跑完了，还回一个 0，意思是"一切正常"。

---

## 二、变量 = 一个贴了名字的盒子

    int age = 18;

这行在干什么？拿一个盒子，贴上名字 age，把 18 放进去。

拆开看：

- `int` —— 盒子只能放**整数**（integer 的缩写）
- `age` —— 盒子上贴的名字
- `18` —— 放进去的东西

盒子有了名字，你随时能把它里面的东西拿出来用：

    int age = 18;
    printf("我 %d 岁\n", age);

咦，`%d` 是什么？

它是一张**占位符**——你在字符串里留个空，后面把要填的东西按顺序写在逗号之后。`%d` 专门填整数。

后面有几个占位符，逗号后面就得跟几样东西，**顺序不能错**。

## 三、加法

    int a = 3;
    int b = 4;
    int c = a + b;      // c 现在是 7

看，你课上学的加法，其实就是这个。

再往下：

    int a = 10;
    int b = 3;
    printf("%d + %d = %d\n", a, b, a + b);

打印出来是 `10 + 3 = 13`。

减、乘、除一样：`-`、`*`、`/`

这里有个新手最容易踩的坑——**两个整数相除，结果还是整数，小数部分直接丢掉**：

    printf("%d\n", 7 / 2);      // 打印 3，不是 3.5

先记住有这么回事，怎么拿小数，我们下一课说。
