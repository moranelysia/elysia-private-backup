# 学习区

这是**你们的学习工作区** —— 爱莉希雅在「学习模式」下看的就是这个地方。
（2026-10-07 建的。她在提示词里被明确告知了这个路径，所以她会自己找到这儿。）

---

## 里面有什么

| 文件夹 | 放什么 |
| --- | --- |
| `材料\` | 课件、讲义、PDF、课本拍的照片……**你自己的原件放这儿**。她默认只读不改 —— 怕她手一抖把你原件改了。 |
| `笔记\` | 你们一起攒的笔记。她说要记的时候会**先问你**，你点头她才写。 |
| `练习\` | 题目、错题、复习用。可以按科目再分子文件夹。 |

## 怎么用

1. 把课件（PPT、PDF、Word、图片都行）丢进 `材料\`
2. 开一段**学习模式**的对话（点左边 `＋ 新对话` 的时候选"学习"）
3. 跟她说一句"我想学这个"
4. 她会去读、跟你讲；讲到该记下来的地方，她会问你要不要记下来

## 按科目分

材料多起来之后，自己开子文件夹就行，比如：

```
材料\
├── C语言\
├── 高数A-1\
├── 人工智能导论\
└── 近现代史\
```

她读得懂中文路径（`[读:材料\C语言\第三章.pdf]` 这样），所以怎么方便怎么来。

这份文件是给她看的说明，同时也是给你的备忘 ——

**"学习进度"那个账本还没做。** 那是下一步的事。现在她不会自动记
"你学到哪了"，你得自己跟她说，或者让她把进度写进 `笔记\` 里。
